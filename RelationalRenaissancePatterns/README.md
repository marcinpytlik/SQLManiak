# Relational Renaissance Patterns

Repozytorium demonstracyjne do serii **Relacyjny Renesans**.

Każdy katalog zawiera:
- krótki opis wzorca,
- problem, który rozwiązuje,
- plan odcinka,
- prosty skrypt `demo.sql`,
- checklistę rzeczy do omówienia,
- status przygotowania.

## Zasada odcinka

1. Pokaż problem.
2. Pokaż naiwną implementację.
3. Zastosuj wzorzec.
4. Dodaj walidację.
5. Omów koszty, ryzyka i antywzorce.
6. Powiedz, kiedy wzorca nie stosować.

## Statusy

- `READY` — demo gotowe do nagrania.
- `STARTER` — przygotowany szkielet do rozwinięcia.
- `ADVANCED` — wymaga dodatkowej infrastruktury lub kilku usług.

Zacznij od `ROADMAP.md`.
