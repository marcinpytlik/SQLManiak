# Training Labs

Materiały szkoleniowe w tym obszarze mają status **LAB / REFERENCE**.

Nie przechowujemy tutaj komercyjnych ofert ani aktualnych opisów szkoleń. Oferta szkoleniowa żyje w repozytorium `sqlmaniak-blog`.

## Microsoft legacy

`microsoft-legacy/` zawiera historyczne materiały laboratoryjne z kursów Microsoft:

- 20761 – Querying Data with Transact-SQL
- 20762 – Developing SQL Databases
- 20764 – Administering a SQL Database Infrastructure
- 20765 – Provisioning SQL Databases

Materiały pozostają dostępne jako źródło ćwiczeń, demo i skryptów, ale nie są traktowane jako aktualna oferta szkoleniowa.
