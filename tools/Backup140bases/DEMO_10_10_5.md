# Demo: 25 baz testowych i podział backupów 10/10/5

## Cel pokazu

Pokazujemy, że konfiguracja backupów może rozdzielać bazy do różnych lokalizacji:

```text
DBA_BCK_TEST_001 - DBA_BCK_TEST_010 -> C:\backup1
DBA_BCK_TEST_011 - DBA_BCK_TEST_020 -> C:\backup2
DBA_BCK_TEST_021 - DBA_BCK_TEST_025 -> C:\backup3
```

## Kolejność

```powershell
sqlcmd -S "syriusz" -E -i .\01_create_backup_config_tables.sql
sqlcmd -S "syriusz" -E -i .\02_create_backup_procedure_by_config.sql
sqlcmd -S "syriusz" -E -i .\09_create_25_test_databases_demo_10_10_5.sql
```

Albo:

```powershell
.\run_demo_prepare_10_10_5.ps1 -SqlInstance "syriusz" -ScriptRoot "."
```

## Sprawdzenie konfiguracji

```sql
SELECT
    BackupBasePath,
    COUNT(*) AS DatabaseCount
FROM msdb.dbo.DBA_BackupDatabaseConfig
WHERE DatabaseName LIKE N'DBA_BCK_TEST[_]%'
GROUP BY BackupBasePath
ORDER BY BackupBasePath;
```

Oczekiwany wynik:

```text
C:\backup1 -> 10
C:\backup2 -> 10
C:\backup3 -> 5
```

## DryRun

Skrypt `09_create_25_test_databases_demo_10_10_5.sql` na końcu wykonuje:

```sql
EXEC msdb.dbo.usp_BackupDatabases_ByConfig
    @BackupType = 'FULL',
    @DryRun = 1;
```

## Realny backup

Po sprawdzeniu DryRun:

```powershell
sqlcmd -S "syriusz" -E -i .\10_demo_run_full_backup_10_10_5.sql
```

## Co pokazać na ekranie

1. Wynik grupowania w `msdb.dbo.DBA_BackupDatabaseConfig`.
2. DryRun — plan backupu.
3. Foldery:
   - `C:\backup1\DBA_BCK_TEST_001`
   - `C:\backup2\DBA_BCK_TEST_011`
   - `C:\backup3\DBA_BCK_TEST_021`
4. Log wykonania:
   `msdb.dbo.DBA_BackupExecutionLog`.
