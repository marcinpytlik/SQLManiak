# DBA Monthly Checklist (1–2h)

- [ ] Restore test (realny restore, nie tylko VERIFYONLY)
- [ ] Kontrolowany failover test (jeśli HA/DR)
- [ ] Przegląd konfiguracji instancji i baz (baseline vs aktualnie)
- [ ] Przegląd uprawnień uprzywilejowanych (sysadmin/securityadmin/db_owner)
- [ ] Patching: Windows + SQL CU (pre-prod -> prod), plan rollback
- [ ] Capacity plan: czy potrzebujesz storage/CPU/RAM w kolejnym kwartale?
