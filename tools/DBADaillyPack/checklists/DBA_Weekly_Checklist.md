# DBA Weekly Checklist (30–60 min)

- [ ] Query Store: top regressed queries (CPU/duration/reads)
- [ ] Index & stats sanity (największe problemy, nie “rebuild everything”)
- [ ] Capacity trend: wzrost DB/log/tempdb/backup size
- [ ] HA/DR: AG/FCI/log shipping — opóźnienia/redo queue
- [ ] Security: zmiany ról serwerowych, nowe loginy, db_owner w krytycznych bazach
- [ ] Patch readiness: co wchodzi w oknie serwisowym?
