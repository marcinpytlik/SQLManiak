# Standards

Standardy określają **jak chcemy zarządzać środowiskiem SQL Server**.

Docelowe obszary:

- SQL Server Build
- Backup & Restore
- Security
- Maintenance
- Patching
- Monitoring
- Capacity
- Database Configuration

Standard nie jest instrukcją krok po kroku. Opisuje wymagania, zasady, wyjątki i oczekiwany stan końcowy.

Do tworzenia nowych standardów używaj [template](../templates/STANDARD-TEMPLATE.md).
