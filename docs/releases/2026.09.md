# SQLManiak DBA Library — Release 2026.09

Release `2026.09` zamyka etap przebudowy repozytorium w spójną **SQL Server DBA Library**.

## Architecture

Dodano warstwę Architecture / ADR:

- Layered DBA Library Operating Model,
- Local TempDB on SQL Server FCI Nodes,
- Side-by-Side Migration SQL Server 2016 → 2022,
- Query Store Baseline Before Compatibility-Level Change,
- Baseline-First Monitoring.

Dodano reference architectures dla:

- SQL Server FCI,
- SQL Server Monitoring,
- SQL Server 2016 → 2022 Migration.
