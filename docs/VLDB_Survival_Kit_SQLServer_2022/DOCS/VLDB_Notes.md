# Notatki — Projektowanie VLDB (SQL Server 2022)
- **Piecemeal restore**: umożliwia start bazy zanim wszystkie filegroupy zostaną przywrócone.
- **Partitioned tables**: sliding window zmniejsza koszty utrzymania.
- **Incremental stats**: minimalizują koszt aktualizacji statystyk.
- **Query Store**: kontroluj rozmiar, cleanup i capture mode.
- **Columnstore**: rozważ na tabelach raportowych; na OLTP ostrożnie (dodatkowe write‑amplification).
