# ⚡ T-SQL – Daily Essentials (VS Code + mssql extension, Windows)

## ▶️ Uruchamianie i wyniki
- **Ctrl + Shift + E** – uruchom zapytanie  
- **Ctrl + Shift + Q** – wyświetl dostępne połączenia / wybierz serwer  
- **Ctrl + Shift + D** – pokaż szczegóły połączenia  
- **Ctrl + Shift + P → MS SQL: Connect** – szybkie łączenie z serwerem  

## ✏️ Edycja i komentarze
- **Ctrl + /** – komentuj / odkomentuj zaznaczone linie  
- **Alt + Shift + ↓ / ↑** – duplikuj linie  
- **Ctrl + Shift + U** – zamień na WIELKIE litery  
- **Ctrl + Shift + L** – zamień na małe litery  

## 🔍 Szukanie i nawigacja
- **Ctrl + F** – znajdź  
- **Ctrl + H** – zamień  
- **F3 / Shift + F3** – następne/poprzednie wystąpienie  
- **Ctrl + G** – przejdź do linii  

## 🖥️ Multi-cursor
- **Ctrl + D** – zaznacz kolejne wystąpienie  
- **Ctrl + Shift + L** – zaznacz wszystkie wystąpienia naraz  
- **Alt + Click** – dodaj kursor ręcznie  
- **Ctrl + Alt + ↓ / ↑** – dodaj kursor w pionie  

## 📂 Pliki
- **Ctrl + N** – nowy plik  
- **Ctrl + S** – zapisz  
- **Ctrl + W** – zamknij plik  
- **Ctrl + P** – szybkie otwieranie plików
